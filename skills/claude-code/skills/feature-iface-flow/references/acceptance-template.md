# 验收报告模板

复制到对话、plan 或 PR「环境验证」中，按实填。

```markdown
## 验收 — <feature 名>

### 目标与成功标准
- 目标: …
- 成功标准: …
- 非目标: …

### 接口
| 接口 | 文件 | 实现文件 | Mock |
|------|------|----------|------|
| … | … | … | … |

### MVP
- **M0（白话）:** …
- **自动化:** `<TestName>` / 命令: `…`
- **结果:** PASS / FAIL（附关键断言）

### 边界
| ID | 白话 | 测试 | 结果 |
|----|------|------|------|
| B1 | … | … | … |

### Gate
| 检查 | 工作目录 | 命令 | 结果 |
|------|----------|------|------|
| unit/contract | … | … | … |
| gates-ci 命中项 | … | … | … |

### Review 摘要
- 阻塞: 无 / …
- 契约缺口: 无 / …

### 残余风险
- …

### 结论
- [ ] 接口测试
- [ ] Gate
- [ ] Test 叙述对齐
→ **通过 / 有条件通过 / 不通过**
```
