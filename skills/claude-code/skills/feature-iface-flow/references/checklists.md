# Checklists — feature-iface-flow

按阶段勾选。缺项 = 未完成该阶段，不要宣称「做完了」。

## Check

- [ ] 已读目标路径 `AGENTS.md` / 命中 skill
- [ ] 已搜索可复用接口、Mock、gate、helper（按行为词）
- [ ] 已列出非目标与必须 gate
- [ ] 与 global/仓库 skill 无职责冲突（或已说明分工）

## Design

- [ ] 目标 / 非目标 / 成功标准可测
- [ ] 开放问题已标阻塞与否
- [ ] 跨边界依赖全部接口化
- [ ] 接口单独文件；实现后缀约定写明
- [ ] 接口注释含调用方、并发、幂等、禁止项
- [ ] MVP 白话路径完整（前置→动作→观察→失败可区分）
- [ ] 边界表自 MVP 展开，含 ID
- [ ] 用户已确认或明确授权跳过确认

## Impl

- [ ] 接口先于实现冻结（或变更同步改契约测试）
- [ ] Mock 仅实现接口；场景表驱动
- [ ] 契约测试可对 Mock 与 Impl 复用（或说明为何不能）
- [ ] 编排 UT 断言顺序/参数/错误/副作用，而非实现细节
- [ ] 每个测试有「意义」一行
- [ ] 正式实现无偷偷不可替换依赖
- [ ] Go 时已走 use-modern-go list
- [ ] 模块测试命令已跑并记录
- [ ] 命中 gate 已跑或书面阻塞

## Test 叙述

- [ ] MVP-M0 与测试名双向可追踪
- [ ] 每个 Bi 有场景白话 + 期望 + 测试
- [ ] 无「无场景」测试残留
- [ ] e2e Mock 回归与真实依赖层分离说明

## Review

- [ ] 无绕过接口的生产路径
- [ ] 接口宽度合理
- [ ] Mock 无生产不可达分支（或仅测试辅助且标注）
- [ ] 错误分类与幂等已覆盖
- [ ] Gate 证据真实
- [ ] 阻塞项已列清

## 验收

- [ ] 接口测试通过
- [ ] Gate 通过或阻塞可接受
- [ ] 叙述与代码 ID 对齐
- [ ] 验收报告已写
- [ ] 若开 PR：转 pr-workflow，不在此重复模板
